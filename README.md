# ICOM CQ Prerecorder

IC-7300・IC-7610・IC-9700のボイス送信（Voice TX）用にWAVを変換します。

## 準備と起動

uvを用意し、FFmpegをPATHに追加します。プロジェクトのルートに `submitted_wav/` を作り、変換元のWAVを入れてから実行してください。

```powershell
uv run cq-prerecorder
```

## SDカード用WAVを作る

| 出力フォルダー | 機種 | 音声形式 | SDカード上の配置先 |
| --- | --- | --- | --- |
| `wav_IC7300/` | IC-7300 | 8 kHz・モノラル・16-bit PCM | `IC-7300/VoiceTx/` |
| `wav_IC7610/` | IC-7610 | 16 kHz・モノラル・16-bit PCM | `IC-7610/VoiceTx/` |
| `wav_IC9700/` | IC-9700（試験的対応） | 16 kHz・モノラル・16-bit PCM | `IC-9700/VoiceTx/` |

起動メニューで **SDカード用WAVを作る** を選ぶと、左に T1〜T8 の割り当て、右に音声候補が表示されます。

- `↑`／`↓` または `W`／`S` で候補を移動し、Enter で割り当てます。
- `←`／`→`、`A`／`D`、または `1`〜`8` で割り当て先を選び直せます。
- 1枠以上を割り当てて `G` を押すと、選んだ枠だけ生成します。`Q` で中止できます。

選んだ音声を `submitted_wav/` から直接変換し、`wav_IC7300/sdcard/`・`wav_IC7610/sdcard/`・`wav_IC9700/sdcard/` に枠番号に対応するWAVを生成します。例えば、T3を選ぶと `voicetx3.wav` を生成します。未選択の枠に既存のWAVがあれば、そのまま残ります。使う機種の `sdcard/` から必要なWAVを、voicetxフォルダにコピペしてください。

## 全音声を変換する

起動メニューで **全音声を変換する** を選ぶか、`uv run cq-prerecorder --convert-only` を実行すると、候補全体を元のファイル名で機種別フォルダー直下に書き出します。どちらのモードも出力先の同名ファイルを更新します。

WAV内の表示名はファイル名から取った半角16文字です。非ASCII文字は `?` に置き換えます。

## IC-9700の対応状況

**IC-9700は実機での動作確認を行っていない試験的対応です。**

IC-9700向けには、16 kHz・モノラル・16-bit PCMのWAVを生成します。T1〜T8のファイル名（`voicetx1.wav`〜`voicetx8.wav`）とSDカードへの配置先は上表のとおりです。

IC-9700で録音した実ファイルをまだ解析できていないため、機種固有の録音日（`ICRD`）とファームウェア情報（`ISFT`）は推測値を埋め込まず省略しています。表示名（`INAM`）は生成します。WAV形式の妥当性と、無線機がVoice TXデータとして認識・再生するかは別の確認事項です。利用前にSDカード上のファイルをバックアップし、実機で読み込み・再生を確認してください。
